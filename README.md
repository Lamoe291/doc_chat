# Local RAG with Hugging Face

A lightweight Retrieval-Augmented Generation system for asking questions to documents built using:

- Hugging Face Transformers
- Sentence Transformers
- FAISS
- Streamlit

## Features

- Upload PDFs
- Semantic search
- Question answering
- Local inference

## Tech Stack

- Python
- PyTorch
- FAISS
- Hugging Face
